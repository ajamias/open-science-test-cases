# Virtualization Test Outline

What has been tested on OpenShift Virtualization (CNV), and what passed.

All runs are against `oac-dev-workload0`, namespace `mm-test` (the networking suite defaults to `vm-test`). Guest images are CirrOS (`quay.io/kubevirt/cirros-container-disk-demo`) for networking and Fedora Linux 41 Cloud Edition (`quay.io/containerdisks/fedora:41`) for everything that needs a real disk. VM disks land on `pure-fb-nfsv4` (provisioner `pxd.portworx.com`), which is what CDI picks on its own.

The test scripts run entirely as the logged-in user, so what they prove is what a real project user can actually do. There are three deliberate exceptions, all documented where they occur:

- the **migration RBAC grant**, applied once per namespace by a cluster admin — see [Finding 2](#finding-2-no-shipped-role-delegates-live-migration);
- the **secondary-network RBAC grant**, likewise once per namespace, because no shipped role lets a user define a secondary network at all — see [Finding 3](#finding-3-secondary-networks-cannot-be-created-or-audited-by-a-namespace-user);
- a single `--as system:admin` in `test-vm-secondary-ipam.sh`, on a **non-mutating read** of the whereabouts `IPPool` objects. These are cluster-scoped, no namespace role can reach them, and they are the only record of who holds which address. The script prints the unprivileged view first and the privileged one second, precisely so the difference between them is visible. Set `ADMIN_IPPOOL_READ=0` to drop the impersonation and see only what an ordinary operator gets.

Detail for every suite, including configuration variables and how each check works, is in [vm-testing/README.md](vm-testing/README.md).
